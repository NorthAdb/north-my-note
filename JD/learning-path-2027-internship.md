## 三、六大学习模块

### 模块 0：编程底座（贯穿全程，优先级 ★★★★★）

**JD 证据**：26 份提数据结构/算法，24 份提操作系统；拼多多"编程底子厚"、快手"扎实的计算机基础"、腾讯"专业软件知识，包括算法、操作系统、软件工程、设计模式、数据结构、数据库系统、网络安全"。

**行动项**：
- **主力语言策略（关键）**：市场语言分布 = Python 72 次（AI/算法岗第一）· Java 47 次（后端岗主流）· Go 37 次（后端岗主流）。**"AI 应用岗看 Python，纯后端岗看 Java/Go"**——走复合路线的你两手都要硬：
  - **Python**：AI 应用/Agent 项目的主力（模块 1/2 全部用它）
  - **Java 或 Go 二选一**：后端岗的敲门砖。腾讯/京东/百度/B站/小红书/OPPO/vivo 后端岗全部点名 Java/Go；你是 Java 基础，**保留 Java 并做一个 Java 后端项目**（Spring Boot + MySQL + Redis + 消息队列），对标百度 AI 开放平台岗（明确要求"熟练掌握 Java，理解 JVM、并发编程、集合框架"）
- 每日 30-60 分钟算法题（LeetCode Hot 100 + 剑指 Offer 为主，目标面试前 300 题量）
- 补计算机基础：操作系统（进程/线程/内存）、网络（TCP/IP/HTTP）、数据库（MySQL + SQL）

**产出物**：无（这是门槛不是亮点）

**时间投入**：每天 1-1.5h，贯穿到 2027.03

### 模块 1：LLM 应用开发（优先级 ★★★★★，2-3 个月）

**JD 证据**：RAG 33 次、Prompt 19 次、工具调用、Context Engineering（淘天/阿里）；百度"大模型应用/agent算法工程师"要求"router分流策略、plan策略、检索rag策略、内容生成质量、工具调用/Deep Research skill效果优化"；阿里"理解短期记忆、中期压缩、长期持久化记忆等 Agent 记忆机制"。

**行动项**（按顺序）：
1. **LLM 原理深化**：从"会调 API"到"懂原理"——Transformer 结构、注意力机制、KV Cache、上下文窗口限制（你在学的 LLM 基础继续深化）
2. **RAG 全链路**（不是"会用"，是"能讲清楚发展、适用场景、受限场景"——阿里原话）：文档解析 → 切分 → Embedding → 向量检索 → 重排 → 答案生成 → 效果评估。落地一个知识库项目
3. **Prompt/Context Engineering**：系统提示词设计、少样本、结构化输出、上下文压缩/管理
4. **Function Calling / Tool Calling**：从 API 层理解工具调用的协议机制（tool schema、参数校验、结果回传、异常处理）

**学习资源**：你在学的 Datawhale LLM 教程 + All-in-RAG 继续；LangChain 官方文档；《Prompt Engineering Guide》

**产出物**：一个带 RAG 的问答系统（GitHub 开源）

### 模块 2：Agent 工程（优先级 ★★★★★，你的主攻方向，2-4 个月）

**JD 证据**：Agent 295 次全场第一；MCP 15 次、Harness 11 次、Skills 7 次、多智能体 20 次、记忆 32 次；字节"多Agent协作、记忆、知识、鉴权、观测全生命周期"；美团"LangGraph、Swarm 框架 + MCP 协议及工具生态"；阿里"MCP、Function Call 开发/集成经验"；小米"Harness优化、评估器优化"。

**行动项**（按顺序）：
1. **框架实操**：LangChain/LangGraph 精熟一个（8+3 次点名），旁通 AutoGen/CrewAI（多智能体 20 次）；Dify 会用（低代码交付岗 1 次，但验证思路快）
2. **MCP 协议吃透**（15 次点名）：理解 MCP 的 server/client 架构，自己写 2-3 个 MCP server（把你在用的工具封装成 MCP）
3. **Skills/Harness 工程**（11+7 次）：把业务能力抽象封装为可复用的 Skill——这正是你在学的方向！用你现有的 Harness 学习继续，落地一个"Agent 干活"的真实工作流
4. **Agent 记忆**（32 次）：短期/长期记忆、记忆检索、压缩；参考小米"快慢双系统记忆架构"、阿里"短期记忆、中期压缩、长期持久化"
5. **多智能体协作**（20 次）：多 Agent 分工/协商/编排
6. **Agent 评测**（76 次，超高频）：评测体系是 2027 市场的独立岗位方向——学评测方法论（成功率/延迟/Token 消耗/工具调用准确率），给你的 Agent 项目搭评测闭环。字节 Agent 评测实习生、MiniMax 大模型算法评测实习生都是可直接投的岗
7. **Agent 安全基础**（可选）：注入攻击、越权、记忆污染（阿里有 Agent 安全评测实习岗）

**学习资源**：你的 Harness 学习资料（walkinglabs harness engineering）+ Anthropic Agent 教程 + LangGraph 官方教程 + MCP 官方文档

**产出物**（这个模块的产出就是简历核心）：
- 一个端到端 Agent 项目：真实解决一个问题（如"GitHub Issue 自动处理 Agent"或"论文阅读综述 Agent"），含记忆、工具调用、评测闭环
- 2-3 个 MCP server（开源）
- 项目评测报告（展示"评测驱动迭代"能力）
