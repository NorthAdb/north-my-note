## 一句话总论

传统「先打基础再实战」的学习顺序，对 AI Agent 开发来说是错的。正确的做法是**以终为始**——先确定岗位需求，再倒推项目和技能树，用 AI 辅助快速产出项目经验。

## 适用人群

- ✅ 想转行 AI Agent 开发但没有项目经验的人
- ✅ 在校学生想找 Agent 相关实习/工作
- ✅ 有基础但觉得学习路线迷茫的人
- ❌ 已经独立上线过 Agent 项目的人（内容偏入门）

## 核心观点：学习顺序是反的

### 传统思路（错的）

```
学 Python → 学 LLM 原理 → 学 LangChain → 学 Agent 框架 → 做项目
```

❌ 问题：还没走到「做项目」就放弃了，或者学完发现已经过时了。

### 正确思路（以终为始）

```
确定目标岗位 → 调研岗位需求 → 看优秀同行的简历倒推技能树
→ 选一个项目 → 用 AI 辅助快速开发 → 复盘沉淀 → 面试
```

---

## 三种项目路线

|    路线    | 做法                | 适合谁            | 推荐案例                      |
| :------: | :---------------- | :------------- | :------------------------ |
| **① 模改** | 基于现有开源 Agent 项目改造 | 想做个人作品、快速出成果   | OpenClaw、Hermes Agent     |
| **② 手搓** | 不用框架自己从零搭建        | 想深入理解原理、面试有料可讲 | RAG 全流程、Agent Loop        |
| **③ 表演** | 做多 Agent 协作的完整系统  | 想展示架构能力、面试加分   | GPT-Search、AutoGen、CrewAI |

> 三者不是互斥的，可以组合使用。

---

## 关键建议

### 1. 用项目倒推学习，而不是先学再做

不要花几个月看完教程再动手。**边做边学**是最快的路径：

```
找项目 → 用 AI 辅助开发 → 过程中遇到什么学什么 → 复盘整理
```

### 2. 给项目加「业务背景」

面试官最怕看到没有业务背景的「玩具项目」。同样是 Agent，你说「我在一个电商公司做了客服 Agent」和「我写了一个 Agent demo」，面试官的关注度完全不同。

> 可以给项目加一个业务场景包装，不一定要真的在公司做过，但要像真的。

### 3. AI 就是你最好的开发伙伴

不要让 AI 替你写代码就完事了。更好的用法：

- 让 AI 帮你拆解项目的每个技术要点
- 让 AI 帮你整理面试可能被问的问题
- 把项目中的坑点都记录下来，这就是你面试时最加分的「实战经验」

### 4. 面试是迭代的，不是一次性的

```
面一次 → 复盘被问到的题 → 补充项目细节 → 再面 → 再复盘
```

这才是最快的成长路径。不要等「准备好了」再去面试——永远不会有完全准备好的那一天。

## 实践清单

- [ ] 确定你想去的岗位（Agent 开发 / AI 应用 / 后端+AI）
- [ ] 找到 3-5 个目标岗位的 JD，总结共同要求
- [ ] 找到 2-3 个优秀同行的简历，倒推技能树
- [ ] 选一个开源 Agent 项目（如 OpenClaw）作为基础
- [ ] 用 AI 辅助开发一个带业务场景的项目
- [ ] 每完成一个模块，让 AI 帮你整理面试可能的提问
- [ ] 面试后复盘，把新问题补充进项目经验
