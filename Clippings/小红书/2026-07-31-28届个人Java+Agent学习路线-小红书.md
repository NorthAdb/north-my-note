# 28届个人 Java + Agent 学习路线

> 来源：小红书用户「天才美少女卡莎」
> 
> 这是一份以 Java 后端求职和 Agent 项目落地为目标的个人经验路线。核心策略是：**基础快速过一遍 → 尽早确定项目并写简历 → 围绕项目补知识和八股 → 算法与投递并行推进**。

## 一、作者的学习时间线

### 1. Java 后端基础阶段

- **2025 年 9 月**决定走开发方向。
- 9—12 月随缘学习 JavaSE、JavaWeb、苍穹外卖、Redis、RabbitMQ 等黑马系列课程。
- 作者的建议是：JavaSE 和 JavaWeb 可以快速过两遍，先对名词和整体结构形成印象，不必前期强行记住所有细节。

### 2. RAG → Agent 项目阶段

- 2025 年 12 月购买知识星球并完成一个 RAG 项目。
- 后续在 5 月将 RAG 项目升级为 Agent 项目。
- 作者认为，纯 RAG 项目在当时的求职竞争力有限，最好继续补充 Agent 能力。
- Agent 项目重点不在“调用了哪个模型”，而在于：
  - 循环（Loop）设计
  - 记忆机制
  - 上下文管理
  - 评测与效果验证
- 文章建议参考小林 coding 关于 Agent 的架构图解，理解项目如何设计和流转。

### 3. 面试与算法阶段

- 开学后开始系统准备面试，结合面渣逆袭和小林 coding 的八股资料。
- 从 9 月开始持续刷题，Hot 100 刷了四遍。
- 面试准备内容包括：
  - Hot 100、Top 150
  - SQL 高频题
  - 多线程打印
  - 双重检查锁
  - 归并排序等常见手撕题
- 作者建议在项目、简历和视频基本完成后，再集中建立自己的八股题库并反复背诵。

## 二、技术学习建议

### Java 后端基础

- **苍穹外卖**：主要用于熟悉 CRUD 和后端项目流程。作者认为当前很多代码可以借助 AI 生成，重点是理解项目整体流程。
- **Redis**：先看基础和高级篇，再结合面试题掌握常见八股；原理细节可以根据目标岗位和面试要求补充。
- **RabbitMQ**：快速理解核心概念，再找一个“MQ 改造黑马点评”类项目实践。
- 简历上可以体现 RabbitMQ、Kafka、RocketMQ 等消息队列，但必须能讲清楚使用场景、可靠性和失败兜底。

### Agent 项目

作者没有推荐某一个具体项目，而是建议重点观察项目是否具备以下设计点：

1. Agent 循环如何运行和终止
2. 工具调用如何编排
3. 记忆如何保存、召回和更新
4. 上下文如何组织和压缩
5. RAG 如何检索、重排和评测
6. 错误、超时和工具失败如何恢复
7. 如何记录 Trace、评估效果和定位问题

> 这些部分比简单地“接入一个大模型 API”更能体现 Agent 工程能力。

## 三、简历与项目策略

### 尽早确定项目

作者建议不要等全部课程学完才开始项目：

1. 尽早确定一个可展示的项目。
2. 项目进行中同步写简历。
3. 围绕简历中的技术名词补知识。
4. 能解释每个设计：为什么这样做、替代方案是什么、失败时如何兜底。
5. 把项目的亮点和关键流程整理成面试叙事。

### 研究同岗位简历

图片中建议在小红书、牛客等平台搜索同岗位的简历求拷打或简历分析内容，观察：

- 同岗位常见项目如何表述
- 技术栈如何组织
- 项目亮点如何量化
- 面试官可能围绕哪些关键词追问

### 面试八股

- 视频看完、项目做完、简历写完后，再系统整理八股。
- 建立自己的题库，至少完整背诵两三遍。
- 再看与目标岗位相关的面经，用于补充传统八股。
- 不要过度关注别人项目的专属问题；优先掌握与你自己简历和通用基础相关的内容。

## 四、投递与面试策略

- 作者建议同时投递大厂和中小厂，不要只盯一个目标。
- 可以使用 Boss 等平台持续投递，作者分享了“一天投递 150 份”的激进做法；这属于个人经验，不应机械照搬。
- Java 后端、Go 后端和 Agent 开发岗位都可以尝试，但每个方向的简历和项目叙事应有所区别。
- 面试过程中要掌握主动权：
  - 不要把面试官当成上级或审判者。
  - 不会专业术语时，可以用自己的话、举例或项目经验解释。
  - 回答自己真正理解的内容，不要为了显得懂而编造。
  - 把面试看成双向选择，失败不等于能力被否定。

## 五、这份路线的可复用框架

```text
Java 基础
  ↓
JavaWeb / Spring Boot / MySQL / Redis / MQ
  ↓
完成一个后端项目
  ↓
RAG 项目：切分、Embedding、检索、重排、引用
  ↓
Agent 项目：工具、循环、记忆、上下文、评测、观测
  ↓
项目简历化：亮点、指标、替代方案、故障兜底
  ↓
八股题库 + 算法 + 模拟面试 + 持续投递
```

## 六、结合我的学习路线的落地建议

这份笔记的求职导向很强，但“基础快速过、后期集中背八股”不适合作为长期学习的全部策略。可以采用**快速建立全景认知 + 在项目中补深度 + 面试前结构化复习**的折中方案。

### Java 后端最低能力底座

- Java：集合、并发、JVM、IO、异常和常用设计模式
- Spring Boot：IOC、AOP、事务、配置、Web 接口和测试
- 数据库：MySQL 索引、事务、锁、慢查询和基本优化
- Redis：数据结构、缓存一致性、穿透/击穿/雪崩、分布式锁
- MQ：消息可靠性、重复消费、顺序、积压和最终一致性
- 网络：HTTP、TCP、鉴权、限流和基本安全

### Agent 工程最低能力底座

- LLM API、结构化输出和 Tool Calling
- RAG 全链路与检索质量评测
- Agent Loop、状态管理和上下文控制
- Memory 的存储、召回、更新和遗忘
- 多 Agent/工作流编排
- Trace、成本、延迟、失败重试和安全护栏

## 七、原帖正文要点

作者原文的核心建议可以概括为：

1. 前期基础知识不必强行记忆，先快速过一遍建立印象。
2. 尽早确定项目并写简历，围绕简历内容反向学习。
3. 项目、视频和简历完成后，系统建立八股题库并反复背诵。
4. 算法保持持续练习。
5. 面试保持良好心态，把面试看作双向选择。
